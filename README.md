# Fintrox.Server

Central accounting platform backend for Fintrox.

## Target architecture

- ASP.NET Core Web API on .NET 10 LTS
- PostgreSQL with Entity Framework Core
- Modular monolith / Clean Architecture
- Multi-organization accounting
- Double-entry ledger
- REST/OpenAPI integration surface for external business applications

The repository is intentionally initialized without application scaffolding. The API solution and projects are introduced in the next implementation phase.
